# Public repository, MIT license

Date: 2026-09-20 · Status: accepted

## Context

The project is meant to be shown to people. SonarCloud is free for public projects only. The recordings are CC0 and
CC BY, melodies and lyrics are public domain.

## Decision

The repository is public, the code MIT. Before publishing it was verified that the secret hosting path appears
nowhere. The sources of the recordings are credited in README and app.

## Consequences

Anyone may read, fork and reuse the code. Quality analysis runs for free.

## Rejected

_Private repository._ It would cost the free quality gate and defeat the purpose of a project meant to be shown.
