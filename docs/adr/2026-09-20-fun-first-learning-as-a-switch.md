# Fun first, learning as a switch

Date: 2026-09-20 · Status: accepted

## Context

Musical instruments get used when the first note rewards. Learning software gets put aside.

## Decision

The default state is the plain instrument. Everything explanatory (note names, solmization, degrees, functions, staff,
cents) is a switch "Show me what you're doing", off by default. There is no "wrong" feedback – except in the explicitly
chosen scoring game mode.

## Consequences

Every new view must be usable without explanation. Groove (band) before theory.

## Rejected

_A tutorial on first start._ Every instrument that greets you with a lesson gets put down before the first
note.

_Marking wrong notes in free play._ There is nothing wrong to play here – that is the whole idea. Scoring
belongs to the game mode a person chooses.
