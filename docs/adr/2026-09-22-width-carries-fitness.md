# Width carries fitness

## Context

The four ranks have to reach the player without being read. Colour alone is weak for this:
it competes with every other use of colour, and it asks for a legend.

## Decision

The width of a melody stripe is its fitness. Notes that carry are wide targets, notes that pull
are narrow ones. Width changes smoothly when the chord changes.

## Why

A wide target is easier to hit. The information therefore does not need to be interpreted at
all — the hand lands on the fitting note more often simply because there is more of it. Nothing
is ever blocked, so the narrow notes stay available for anyone who wants them.

The visible breathing of the keyboard on a chord change is also the clearest possible lesson
that fitness depends on harmony, not on the key.

## Rejected

_Coloured bars at the foot of each key._ Read as a chart, not as an instrument.

_Arrows showing where a pulling note wants to resolve._ Correct but not self-evident; the
player found them puzzling rather than helpful.

_A field of pebbles with size as the signal._ Beautiful and the least playable of all versions —
without a fixed left-to-right grid the hand has nothing to aim at.
